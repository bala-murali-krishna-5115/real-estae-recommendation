# real-estate-recommendation

**Nesta — AI Property Recommendation Assistant**

Nesta is a conversational chatbot that helps real estate buyers find the right property in a few taps, no forms or filters to dig through. It asks about budget, preferred city, property type, and bedroom count, then searches live listings from sites like 99acres, MagicBricks, and Housing.com to surface real, currently-available matches — not a static catalog.

Each recommendation comes with an estimated EMI breakdown (down payment, loan amount, monthly payment), an embedded Google Map of the location, and a direct link back to the original listing. Once a buyer shortlists a property, the bot captures their contact details and can book a site visit on the spot — turning a casual browser into a qualified lead automatically.

**Key features:**
- Guided conversational intake (budget → city → type → bedrooms)
- Real-time property search via live web data, not hardcoded listings
- Automatic EMI calculator per listing
- Embedded map + "view original listing" link for every match
- Built-in lead capture and site-visit booking
- Clean, professional interface designed to sit on any real estate or builder website

**Best for:** real estate agencies, individual brokers, and builders who want to qualify leads automatically and give site visitors an instant, useful first interaction instead of a static contact form.
